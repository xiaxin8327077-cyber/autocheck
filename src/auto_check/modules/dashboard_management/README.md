# 看板管理模块

“看板管理”用于维护两个固定看板的数据来源，不能新建第三个看板：

- 金融监管报表报送大屏：7 个内置数据区域。
- 金融监管报送流程大屏：3 个内置数据区域。

页面使用浏览器会话存储分别记住当前看板及各看板最后选择的数据区域，刷新浏览器后恢复原选择；区域已不存在或不可用时才回退到当前看板第一个区域。

顶部两个看板使用完整的紧凑 Tabs 组件切换，当前项通过浅蓝背景、主题色加粗文字和 3px 底部选中线突出显示。切换区右侧只提供一个“预览当前看板”菜单，悬停后可选择“接口数据”或“看板页面”；关闭预览后焦点返回当前看板 Tab，下拉菜单随即收回。接口数据预览通过 `GET /api/modules/dashboard-management/boards/{board_code}/preview` 按已保存配置读取全部启用区域，并展示接口完整 JSON 返回；单个区域读取失败时在该区域返回错误，不阻断其他区域。看板页面预览加载模块内置的两套独立页面，并调用同一接口把当前已保存配置的数据填入页面；预览使用接近全屏的弹窗展示，支持右上角“关闭”和 Esc 关闭，点击遮罩空白处不会关闭。

模块迁移初始化上述 10 个内置区域和 21 个内置字段。管理员可以在现有区域追加自定义字段，也可以在任一固定看板内新建自定义区域并一次定义首批字段。内置编码、字段别名和字段类型是后续契约，不能修改；自定义区域和字段支持调整显示名、说明及启用状态。用户创建的区域支持删除，删除时会同时物理删除其字段和来源配置；系统内置区域禁止删除。编辑区域前页面会重新读取最新版本，避免刷新或后端重启后因缓存版本过旧而误报并发更新。

三个内置 `month` 字段的展示格式直接写入字段说明：“月度信托项目数量”使用 `1月`～`12月`（例如 `8月`）；“报表对账完成时间”和“报表校验问题处理”使用 `YYYY-MM`（例如 `2026-08`）。打开对应字段的管理弹窗即可查看；该说明仅描述看板展示契约，不改变 SQL 校验或接口返回逻辑。

## 数据来源和保存规则

每个数据区域只能选用一种来源：可用时选择系统数据，或选择自定义 SQL。一个区域只能保存一条 SQL，这条 SQL 必须一次返回该区域全部启用字段；系统数据区域追加自定义字段后必须改用自定义 SQL。SQL 或数据源变更、字段新增/停用/恢复后都会使上次测试失效，必须重新测试才可保存。

系统数据模式由模块按内置指标自动生成只读 SQL，并直接在当前 AutoCheck 应用数据库连接中执行。页面来源区只展示来源功能和应用数据库名，数据表中文名、物理表名、字段中文名与查询别名改在系统生成 SQL 顶部以注释展示，并支持返回前 10 行预览；预览表头使用区域字段配置中的中文名，表头与内容统一居中。右侧使用紧凑的区域名称与状态标签代替重复的“基本信息”分组，配置内容由页面统一滚动，不生成内层纵向滚动条；数据源下拉与来源切换器等宽，桌面双栏布局下系统生成与自定义 SQL 编辑框均自动占用剩余页面高度，并禁止手动拖拽改变尺寸。当前系统口径分别来自报送导航统计快照、核对历史、报表特殊处理记录以及报送导航流程/月度报送计划；系统表尚未初始化或没有数据时不会生成模拟结果。

“报表对账完成时间”以 `run_headers.run_date` 作为报送期，关联 `reconcile_runs.total_count`，筛选总差异为 0 的自动对数历史，并取最小的 `run_at`。

“季度报表特殊处理”按特殊处理时间统计本年度 `pending`（待确认）与 `completed`（已确认）记录；草稿和作废状态不统计。删除操作会物理删除主记录，因此已删除记录自然不会进入统计。

“当月报表报送时间对比”读取启用的报送导航流程、当月完成快照和月度报送计划，并按流程名称排除“人行大集中”。

SQL 接受任意单条 `SELECT`，或最终返回 `SELECT` 的 `WITH` 查询，支持行注释、块注释、数据库原生函数、自定义函数、操作符、自定义类型及不带 schema 的表名；语法与对象是否有效交由目标数据库判断。应用仍禁止写入、DDL、授权、锁定及多语句，查询连接启用只读事务；结果需覆盖全部字段，标量区域至多一行，预览最多展示 10 行。系统不会存储数据源密码到模块表，错误响应也不会回显连接串、密码、SQL 原文、驱动堆栈或本地路径。

## 运维与验证

为数据源创建专用、最小权限的只读账号，并按实际使用的 PostgreSQL 或 MySQL 数据库完成连通性、超时和权限集成验证；单元与集成测试中的 SQL 执行器替身不会覆盖真实网络驱动验证。停用 `dashboard_management` 会移除入口、模块 API 和静态资源，但不会删除 `dashboard_management_regions`、`dashboard_management_fields`、`dashboard_management_source_configs` 三张表或其中的配置数据；重新启用后目录和来源配置会恢复可读。
