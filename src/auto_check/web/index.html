关于系统

系统简介和帮助入口

本系统用于自动核对项目余额差异，支持多种数据源，提供详细的差异分析和历史记录功能。

主要功能

  • 自动对数：根据预设规则自动核对项目余额
  • 差异分析：智能识别差异原因并提供详细说明
  • 历史记录：保存每次核对结果，支持对比分析
  • 数据导出：支持导出核对结果为 Excel 文件
  • 多数据源：支持 PostgreSQL 和 MySQL 数据库

技术栈

  • 后端：Python 3.12 + psycopg + PyMySQL
  • 前端：原生 HTML/CSS/JavaScript
  • 打包：PyInstaller
