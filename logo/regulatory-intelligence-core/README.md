# 监管智核品牌资源包

这套资源基于原品牌方案中的“双环对勾”图形：蓝色圆代表数据核对，金色圆代表监管校验，交叠区域代表自动对账与监管核验的统一结论，下方虚线节点代表流程落点和核心判定。

## 资源清单

- `mark.svg`：主图形标识，适合侧边栏、关于系统、加载页。
- `favicon-64x64.svg`：浏览器标签页和小尺寸图标。
- `logo-horizontal.svg`：浅色背景横向主标。
- `logo-horizontal-dark.svg`：深色背景横向主标。
- `logo-stacked.svg`：竖向居中展示版本。
- `app-icon.svg`：应用图标版本。
- `tokens.css`：品牌色变量。
- `brand-preview.html`：效果预览页。
- `preview-screenshot.png`：效果预览截图。
- `brand-manifest.json`：资源包元数据。

## 主色

- 深蓝：`#0f172a`
- 品牌蓝：`#3466d9`
- 亮蓝：`#6aa4ff`
- 科技青：`#2aa7c8`
- 监管金：`#d98711`
- 亮金：`#ffbd38`

## 使用建议

- 浅色界面优先使用 `logo-horizontal.svg` 或 `mark.svg`。
- 深色界面优先使用 `logo-horizontal-dark.svg`。
- 浏览器 favicon、顶部紧凑导航和按钮图标使用 `favicon-64x64.svg`。
- 对外展示、启动页、封面和品牌卡片使用 `logo-stacked.svg`。
