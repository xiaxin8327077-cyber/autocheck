## 已定位的问题

1. “产品期末业绩表现不能包含%或‰”的有效文字谓词曾被规则协议拦截，因为旧版只允许关键词作筛选，不能直接作为异常表达式。只检查非空不能替代这项检查。
2. 募集表的期末业绩表现直接取自项目表原字段，原表与同月归档的双来源声明未被检索器认作同一个来源，造成选表绕路和重复确认。无明确明细限定时使用经文档证明的原字段，存在明细范围时保留其范围。
3. “存续项目实收信托”的主体与指标边界被误合并成项目端独占别名；缓存还绕过文档候选完整性复核，使单方案和缺建议重复出现。现在区分范围主体与显式维度限定，并重新核实缓存中的候选。
4. 模型偶尔把字典业务名称当成码值，或把字段名写成分类名称。修复会以原文和完整字典核实明确标签；仍不能确定时提供真实文档选项，不把错误分组当可执行条件。
5. 同一个分类名称对应多个物理码时，不擅自缩窄成一个；选项中展示码值，确认后落实实际选择。
6. SUM 汇总的匹配组比较与旧缺关联策略声明不一致，导致本来可执行的 `exclude` 被误拦。按匹配组比较应使用对应的 INNER JOIN，历史合法定义保持原执行含义。
7. 同一指标的区间上下界被分成两个独立字段选择，能够产生混搭口径；泛称指标的空值备选有时被模型铺成复合条件。现在在真实文档及原需求能够证明同一指标时共享选择；明确点名多个字段或要求全部字段时保留复合检查。
8. 补建议请求漏掉其他相关文档字段及主方案的完整备选列表，还把单卡跨表规则误当成单表。建议生成应核实实际涉及的文档、全部主选项、分类字典和启用口径，而不能只看当前默认绑定字段。

## 表达能力边界

| 表达 | 当前处理 |
| --- | --- |
| 空值、非空、数值大小/相等、同一行字段比较 | 可生成；数值 NULL 按已确认口径，其他类型保留自身约定 |
| 文本相等、不等、包含任一或不含任何关键词 | 可生成；严格区分英文大小写，词按字面匹配 |
| 加减乘除、括号、同一行已有上期字段 | 可生成；除数为零单列待核查 |
| 最多 8 个平面 AND/OR 异常条件、最多 8 项 AND 范围筛选 | 可生成；不把它们混成额外业务检查 |
| 同源两表、文档证明的键和同日比较、右表 SUM 汇总 | 可生成；真实关系不明时提供选择或说明缺口 |
| 多业务维度、字段口径及独立补充建议 | 有据时保留，推荐不等于代替选择；采纳加入原方案列表 |
| 三表及以上、跨数据源、任意子查询、窗口统计 | 当前结构化规则不支持，不应伪造可执行 SQL |
| 任意嵌套布尔树、任意 OR 范围分组、复杂正则、任意函数 | 当前有限 DSL 不完整支持；纯字面词表可无损转为关键词条件 |
| 没有引号或明确词界的“包含甲和乙” | 仍可能按整个字面词解释；本轮明确引号及 `或`、`\|` 词表已验证，不能外推为任意自然语言合取都已支持 |
| 自动找上一期记录、日期偏移/天数运算、跨行计算、任意聚合 | 不能等同于已有同一行上期字段及已支持 SUM；需按实际能力说明 |

数值列的字符检查按数据源原生文本转换执行。文档中两处业绩表现均为 `numeric`，合法入库数值本身不能保存百分号或千分号；该事实应在提示中说明，不伪造含符号的数值样本。一般浮点指数与尾数显示未证明跨方言完全相同。

能力范围和文档歧义须与模型格式错误分开报告。结构兼容只能采用能够证明不改变含义的转换；无法核实的字段、阈值、逻辑关系或换算不能默认猜测。
