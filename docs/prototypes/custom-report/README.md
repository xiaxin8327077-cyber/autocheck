# 自定义报表设计 - HTML 预览原型

## 预览方式

直接用浏览器打开 `custom-report-prototype.html` 即可查看静态效果。

## 原型内容

页面包含两个区域：

1. **报表设计主界面** — 完整的三栏布局（表列表 / 设计画布 / 配置面板），底部附带数据预览表格和分页
2. **保存模板弹窗** — 点击「保存模板」按钮时弹出的对话框

## 对应方案要点

| 区域 | 说明 |
|------|------|
| 顶部工具栏 | 模板下拉框、删除/保存/预览/导出按钮 |
| 左栏 | 数据源选择 + 表列表（带添加到画布按钮） |
| 中栏 | 画布区：表卡片（字段勾选）、表间关联可视化 |
| 右栏 | 三个 Tab：表关联配置 / 展示列配置 / 筛选条件 |
| 底部 | 预览表格 + 分页 |
