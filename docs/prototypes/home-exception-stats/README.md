# 首页重点异常统计原型

本目录保存首页重点异常统计模块的静态原型和验证截图，用于后续实现或视觉对比。

## 文件

- `home-exception-stats-prototype.html`: 基础版首页重点异常统计原型。
- `home-exception-stats-vitality-wide-prototype.html`: 宽版活力主题原型。
- `screenshots/`: 不同状态下的截图，包括默认、暗色模式、抽屉展开和布局迭代状态。

## 说明

这些文件目前不是运行时代码，未接入 `src/auto_check/web`。如后续实现该模块，需要同步兼容默认太空主题和暗色模式，并按项目约定更新 README、应用内更新日志和相关测试。
