## 配置与复用

2026-11-20 本地确认口径：金额字段在文档未特定标注单位时按元，文档明确标注时按文档换算。监管报表的项目实收比对采用 `proj_info_dtl_pboc.f_equity_total_4001_bal`，与同一 `c_projinnercode`、同一 `d_cldate` 的募集明细 `raise_info_dtl_pboc.f_end_share` 合计比较；差额不为 0 即列异常，容差为 0，不改用乘单位净值后的 `f_end_amt`。项目端与募集端的非负检查分别保留，汇总差异核对作为独立补充方案。该业务事实已通过现有知识设置保存并启用于本地应用库，不作为后端表名或字段名判断分支；其他环境需同步对应的可编辑知识配置。

- 「校验设置 → 信托业务知识」复用校验设置管理员权限。有界草稿与启用快照独立；预览不落库，保存草稿不切换启用快照，启用/停用需要显式操作。并发修改按版本拒绝覆盖。初始条目仅作可编辑草稿，不默认启用。
- 下一次分析在现有选表模型调用前，按数据源、适用日期和需求匹配最多 4 条、约 4 KB 摘要。没有明确历史日期时使用当前中国日期；明确多个不同期间且无法唯一判定时，不注入带日期约束的知识。该日期只筛知识，不替代规则的报告日期字段。
- 服务内存按用户、数据源、活动文档及启用知识版本复用目录及同一组摘要，缓存 10 分钟、每层最多 64 组；先检查启用版本，不复用旧需求、选择或 SQL。关闭模块/重启后不保留。选表与主规则生成按证据合并或展开，跨表方案必要时用精简的独立请求补全建议，仍共用本次模型输出额度；没有学习预调用。当前通用聊天接口不传缓存控制或会话 ID，是否由模型提供商自动命中输入缓存未证实；只保证本地复用，模型请求仍带短摘要。
- 新增模块迁移 011，仅管理知识表；部署时由宿主迁移，需要按既有流程重启。回退前先停用知识并备份应用库，旧代码不读取该表，无需删除。

### 设计边界

1. 在「校验设置」增加模块内的「信托业务知识」入口。条目包括主题、可用摘要、证据来源、适用对象/数据源、适用起止日期、版本和状态。由有校验设置权限的人员编辑、预览和启用；不会覆盖现有生成提示词。
2. 分开维护**公开监管知识**与**本地确认口径**。公开资料解释术语、业务层级与可能的校验方向；活动文档验证本地表、字段、关联键、字典和取数逻辑。文档或本地口径缺失/冲突就提示缺口，不把公开知识当成本地字段证据。
3. 每次分析只附带命中的少量已启用摘要和来源版本，供选表与规则生成参考，不训练模型、不联网检索、不发送业务数据行。已有 SQL 白名单、支持能力、预览与确认门禁不变；不自动保存、启用或执行规则。
4. 首轮合成验收：项目与合同不混比；只在同项目、同期间且金额和币种口径可核对时建议汇总一致性；通识不替代三个状态字段的本地字典；法规未生效时不作为当前强制规则。
