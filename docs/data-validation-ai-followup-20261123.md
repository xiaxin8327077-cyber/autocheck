## 本次业务口径

项目表覆盖公司全部产品项目，不代表每个项目都拥有贷款、收益权、理财等各类合同。

- 普通字段比较、跨表比较及汇总比较只检查同项目、同数据日期下实际存在且符合范围的明细。
- 无明细、只有其他期间明细、明细全部不在检查范围时，不自动加入本条异常。
- 缺明细可作为独立补充建议；必须先明确哪些业务项目应当有这类明细。范围证据不足时在建议中保留待确认前提，不要求全部产品项目都存在该类合同。
- 已存在明细中的字段 NULL 继续按该规则已经确认的空值口径处理，不与没有合同混淆。
