# 自动对账逻辑说明

本文档以纯业务语言描述自动对账功能的完整判断逻辑，不涉及技术字段和代码细节。

## 一、整体流程

系统对账按以下大步骤执行：

1. 从主差异表中读取指定日期下资产合计与负债及权益合计不相等的项目。
2. 对每个差异项目，按优先级逐步排查原因。
3. 将排查结果记录为差异类型、匹配状态和具体原因。

排查顺序为：估值表资产合计校验 → 资产端分析 → 实收本金分析 → 负债及权益端分析。前一步能完整解释差异时，不再进入后续步骤。

## 二、金额比较规则

所有金额均采用精确比较，不允许任何误差。只要两个金额不完全相等，就视为存在差异。

## 三、第一步：估值表资产合计校验

系统从估值表中读取该项目的资产合计金额（科目代码 0004），与主表中的资产合计进行比较。

- 如果估值表中找不到该项目的资产合计，直接判定为"暂无法确定"，不再继续。
- 如果两者相等，说明资产端没有问题，跳过资产端分析，直接进入实收本金和负债权益分析。
- 如果两者不相等，进入资产端分析。

## 四、资产端分析

### 4.1 判断方向

比较主表资产合计与估值表资产合计的大小：

- 主表小于估值表：预判为"资产缺失"，即主表可能少记了资产。
- 主表大于估值表：预判为"资产重复"，即主表可能多记了资产。

### 4.2 匹配具体资产

系统计算两个金额的差额绝对值，然后在估值表中查找以 1 开头的资产类科目，尝试找到一个或多个科目的金额正好等于这个差额。

匹配按以下优先级进行：

1. **单科目录入**：某一个科目的金额恰好等于差额。
2. **同科目汇总**：同一个科目下的多行金额汇总后等于差额。
3. **多科目组合**：多个不同科目的金额组合汇总后等于差额。
4. **分组组合**：当全部末级科目组合候选过多时，按科目前四段分组后再做组合匹配。
5. **组合候选过多**：候选行数或组合状态数超过上限时停止匹配，避免系统卡死。

匹配到具体资产后：

- 如果是资产缺失，进入资产缺失细分链路。
- 如果是资产重复，进入资产重复细分链路。

匹配不到具体资产时，进入资产差异链路。

### 4.3 资产缺失细分

对每个命中的资产，系统根据科目编码识别资产类型（债券、股票、公募基金、私募基金、特定目的载体、贷款、股权投资、逆回购、信托计划收益权、资产收益权等），然后做进一步核查：

**债券、股票、公募基金、私募基金**：
- 先查证券余额表，确认该证券是否存在且金额不为零。
- 再检查相关人行字段是否填写完整。
- 最后检查对应业务报表明细表是否有数据。

**特定目的载体**：
- 用科目名称匹配资产管理系统的标的信息。
- 如果匹配不到标的，原因标记为"AM标的缺失"。
- 如果标的一致但合同投融资余额为零，原因标记为"合同投融资余额为0但FA科目余额不为0"。
- 标的和余额都正常时，进一步检查特定目的载体明细表、资产类型字段等。

**贷款**：
- 查资产管理系统的投融资余额表。
- 再检查贷款明细表是否有数据。

**股权投资**：
- 查资产管理系统的投融资余额表。
- 检查股权投资类别字段是否填写。
- 再检查股权明细表是否有数据。

**逆回购**：
- 检查存续回购业务表中回购金额或佣金是否存在空值。

**信托计划收益权和资产收益权**：
- 分别查对应的投融资余额表和业务报表明细表。

### 4.4 资产重复细分

对命中的私募基金资产，检查其在证券信息表中是否为私募产品但在资产管理系统中不为私募产品。如果是，记录具体原因。其他类型的资产重复目前不做进一步细分。

### 4.5 资产差异链路

当无法直接命中具体缺失或重复的资产时，系统进入资产差异分析，依次检查以下四类差异：

**债券本金差异**：
- 取估值表中债券本金科目的金额，与证券余额表中同一只债券的金额进行比较。
- 逐只债券计算差额，汇总所有债券差异。

**贷款合同差异**：
- 取估值表中贷款科目的金额，与资产管理系统中同一合同的投融资余额进行比较。

**财产权合同差异**：
- 取估值表中财产权科目的金额，与资产管理系统中同一合同的投融资余额进行比较。

**逆回购差异**：
- 取估值表中逆回购科目的汇总金额，与存续回购业务表中逆回购金额进行比较。

将以上四类差异汇总后，与资产端总差额进行比较：

- 如果汇总差异等于资产端总差额，说明资产端差异已被完整解释。
- 资产端解释后如果还有剩余差额（即估值表资产合计与负债及权益合计之间仍有差异），则继续进入实收本金和负债权益分析。
- 如果汇总差异不等于资产端总差额，资产端差异未完整解释，标记为"资产差异"，不再继续。

## 五、实收本金分析

资产端确认正确后，系统开始检查实收本金。

### 5.1 整笔实收本金缺失或重复

- 如果主差异恰好等于FA实收信托科目余额，判定为"实收本金缺失"。
- 如果主差异恰好等于FA实收信托科目余额的相反数，判定为"实收本金重复"。

### 5.2 实收本金差异

如果整笔缺失/重复未命中，系统比较主表实收本金余额与FA实收信托科目余额：

- 如果两者不一致，且其差额恰好等于主差异，判定为"实收本金差异"。
- 进一步细分：比较DM TA汇总与DWS TA汇总是否一致；检查DM表中客户类型为空的记录金额是否能解释实收差异。

### 5.3 实收本金不能单独解释时

如果实收差额不能单独解释主差异，系统计算剩余差额，继续进入负债及权益端分析。此时实收差额会作为第一段具体原因，剩余差额交给后续链路处理。

## 六、负债及权益端分析

### 6.1 匹配负债及权益科目

系统从估值表中读取非 1 开头的科目（排除汇总类科目），尝试匹配待解释的差额。

匹配优先级与资产端相同：单科目 → 同科目汇总 → 多科目组合 → 分组组合。

- 匹配到具体科目后，根据差额方向判定为"负债及权益科目缺失"或"负债及权益科目重复"。
- 如果匹配到正回购科目，额外标记为正回购缺失/重复。

### 6.2 正回购金额细分

如果无法直接命中具体负债及权益科目，系统进一步比较估值表中正回购科目的金额与存续回购业务表中正回购金额：

- 如果正回购差异恰好等于待解释差额，判定为"负债及权益科目差异"，匹配状态为已解释。
- 如果正回购差异不为零但不等于待解释差额，标记为部分解释。
- 如果正回购也没有差异，标记为"未解释"。

## 七、组合差异类型

当资产端差异被完整解释后仍有剩余差额时，系统会将资产差异与后续链路的结果组合展示。例如：

- 资产差异 + 实收本金差异
- 资产差异 + 负债及权益科目差异
- 资产差异 + 实收本金差异 + 负债及权益科目差异

具体原因中的编号会连续顺延，例如①逆回购差异、②实收本金差异、③正回购差异。

## 八、匹配状态说明

每条对数结果都有一个匹配状态：

- **已解释**：已经命中明确规则，或细分差额完整解释了当前差异。
- **未解释**：只能定位到一级差异类型，但不能完整解释具体明细。
- **组合候选过多**：组合匹配的候选行数或状态数超过上限，程序停止枚举。
- **暂无法确定**：估值表缺少资产合计，或所有规则都无法归类差异。

## 九、历史记录与增量差异

每次对数完成后，系统自动保存历史记录，并与上一次同日期、同数据源配置的结果进行比对：

- 新增差异：本次有但上次没有的项目。
- 减少差异：上次有但本次没有的项目。

比对依据是项目编号和差异金额。差异金额相同但原因变化的情况不会被标记为新增或减少。

## 十、导出与展示

结果页面、历史详情页和导出的Excel文件使用同一份核对结果：

- 差异类型：反映一级判断结果，组合类型用加号连接。
- 具体原因：反映细分判断结果，使用带圈数字编号，多个原因换行展示。
- 差异原因详情：展示完整的判断过程和数据对比。
- 处理脚本：针对债券DM差异等场景生成的核查建议。
