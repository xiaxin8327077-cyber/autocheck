# 异常明细采用 SQL 别名

2026-11-19，按用户最终选择，取消文档中文名映射／缓存方案，动态明细表头全部采用实际 SQL 返回列名（即显式 `AS` 别名，未指定时为字段名）。不查询文档、不读取字段备注、不调用模型转换。

- `cldate AS "数据日期"` → `数据日期`。
- `cldate AS data_date` → `data_date`，不再自动替换为中文。
- 支持未引用的中文别名、PostgreSQL 双引号和 MySQL 反引号别名，以及引用内的空格、逗号和转义引号。
- 只扩展结果投影识别和表头展示，不放宽只读 SQL 守卫、数据源权限、返回列白名单与数量／字节上限。不猜测此前不支持的复杂自定义 SELECT 投影。
- 别名及真实查询值保存为执行快照并进入导出；前端直接使用快照列名，旧备注不再覆盖别名。
- 新生成的规则在 SQL 中按可信文档字段名输出中文 `AS`，派生列使用“异常说明”等业务名称。规则定义保存内部角色与实际别名的映射；执行器通过该映射读取业务键、项目编号和比较值，结果页仍直接使用实际 SQL 列名。既有版本继续使用原 SQL 和哈希，自定义中文列名不用于猜测内部角色。
- 无中文名称或现有平台不能安全处理的特殊名称回退到物理字段名；重复名称加角色后缀，遵守 PostgreSQL/MySQL 标识符长度。新编译结果的 CSV/XLSX 保留校验值和比较值的物理字段来源说明，旧结果仍沿用历史接口。

验证：定向 53 项通过，包含 SQLite 实际查询→异常快照→CSV，中文别名、值 0、空值、历史记录、前端别名不被备注覆盖及精简规则编辑回归。运行于合成数据，未执行真实业务校验。更大范围测试与源码重载按当前会话协调记录执行。
