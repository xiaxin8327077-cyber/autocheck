# 自动对数组合候选报表反查映射表

本文档用于补充“金额命中后再反查报表实际值”的规则。  
填写目标：把每类可能命中的科目类型，对应到具体报表表名、过滤字段、匹配字段和金额口径，后续用于判断组合命中是否为误报。

## 填写口径

- “源头核对”指当前已经在 DM、AM、TA、存续回购业务表等源表做的核对。
- “报表反查”指命中候选后，再去资负数据子系统或其他报表明细表确认该对象是否已经正常生成、金额是否正确。
- 如果报表明细存在且金额正确，通常说明该候选只是金额碰巧命中，应从候选中剔除或降级为未解释。
- 如果报表明细不存在、关键字段为空或金额不一致，才作为具体原因继续解释。
- 先补“高风险组合命中”需要反查的表，单行命中和已有强源头证据的类型可后补。
