# 对数总览首次执行统计与质量卡片调整设计

## 目标

- 修复“执行趋势”日期下拉框在“报送导航”成为默认页面后被错误拉伸为整行的问题，并将宽度固定为 150px。
- 将“对数质量”和“差异类型分布”的统计口径调整为当前报告期第一次执行。
- 移除“对数质量”中的质量分、圆环和评价标签，仅保留状态分布。

## 范围

本次只调整“对数总览”页面。顶部统计卡、执行趋势图本身、多指标趋势图和“高频差异项目”的数据口径保持不变。

## 下拉框修复

主干分支的日期下拉框使用 `width: auto` 和 `min-width: 150px`。当前分支新增“报送导航”为默认页面后，自定义下拉框在隐藏的“对数总览”中初始化，元素宽度测量为 0，组件因而使用 `100%` 兜底宽度。

将日期下拉框和增强后的自定义外壳都固定为 150px，并固定其弹性布局基准，避免隐藏初始化测量结果和父容器剩余空间再次将控件拉伸。规则只作用于执行趋势日期框，不影响其他页面控件。

## 统计口径

“对数质量”和“差异类型分布”只从当前最新报告期取数。该报告期内按执行时间升序排列，取最早一次执行；执行时间相同时按记录 ID 升序稳定排序。

选出的当前报告期首次执行记录分别用于：

- “对数质量”：统计各匹配状态的数量，并以该次执行总数计算状态占比。
- “差异类型分布”：统计各差异类型的数量，并以该次执行总数计算类型占比。

不再汇总最近 12 期首次执行。“高频差异项目”仍最多读取最近 12 个报告期，并继续沿用当前按报告期去重的统计逻辑。

## 对数质量展示

删除质量分数字、圆环、“质量分”文字以及“优秀／稳定／需关注”评价标签。状态分布区域扩展使用卡片可用宽度，继续展示状态名称、进度条、数量和占比。“对数质量”和“差异类型分布”标题旁不再展示“近 X 期”，高频差异项目的范围说明保留。

## 兼容与验证

- 活力主题、沉稳主题和暗色模式均保持可读与布局一致。
- 新增前端静态测试，覆盖日期下拉框及其自定义外壳固定宽度、当前报告期首次执行选择规则、两块统计共同使用该次执行数据、范围文案移除，以及质量分相关节点和计算逻辑被移除。
