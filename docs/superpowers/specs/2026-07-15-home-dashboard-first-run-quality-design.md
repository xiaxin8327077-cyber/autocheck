# 对数总览首次执行统计与质量卡片调整设计

## 目标

- 修复“执行趋势”日期下拉框在“报送导航”成为默认页面后被错误拉伸为整行的问题，并保持主干分支原有的自适应宽度效果。
- 将“对数质量”和“差异类型分布”的统计口径调整为近 12 个报告期中每期第一次执行。
- 移除“对数质量”中的质量分、圆环和评价标签，仅保留状态分布。

## 范围

本次只调整“对数总览”页面。顶部统计卡、执行趋势图本身、多指标趋势图和“高频差异项目”的数据口径保持不变。

## 下拉框修复

主干分支的日期下拉框使用 `width: auto` 和 `min-width: 150px`。当前分支新增“报送导航”为默认页面后，自定义下拉框在隐藏的“对数总览”中初始化，元素宽度测量为 0，组件因而使用 `100%` 兜底宽度。

保留主干现有 CSS，不写死日期框宽度。进入“对数总览”并完成页面显示后，对日期下拉框及其自定义外壳重新测量，使其恢复按内容自适应、最小 150px 的主干效果。重新测量只作用于执行趋势日期框，避免影响其他页面控件。

## 统计口径

历史记录仍按报告期选取最近 12 期。每个报告期内按执行时间升序排列，取最早一次执行；执行时间相同时按记录 ID 升序稳定排序。

选出的 12 条以内首次执行记录分别用于：

- “对数质量”：汇总各匹配状态的数量，并以汇总总数计算状态占比。
- “差异类型分布”：汇总各差异类型的数量，并以汇总总数计算类型占比。

不再对同一报告期内的全部执行次数求平均。“高频差异项目”继续沿用当前按报告期去重的统计逻辑。

## 对数质量展示

删除质量分数字、圆环、“质量分”文字以及“优秀／稳定／需关注”评价标签。状态分布区域扩展使用卡片可用宽度，继续展示状态名称、进度条、数量和占比。近多少期的范围说明保留。

## 兼容与验证

- 活力主题、沉稳主题和暗色模式均保持可读与布局一致。
- 新增前端静态测试，覆盖隐藏页面下拉框重新测量、每期首次执行选择规则、两块统计共同使用首次执行数据，以及质量分相关节点和计算逻辑被移除。
