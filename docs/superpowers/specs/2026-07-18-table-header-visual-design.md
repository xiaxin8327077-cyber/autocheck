# 表格表头灰色统一设计

## 背景

当前主列表、历史详情及弹窗表格存在多套表头样式。用户管理表头使用较深的不透明表面灰色和清晰文字，历史列表、对数结果详情及部分弹窗表格则使用被混浅的背景色和较轻文字，因此在带渐变的页面上显得更浅。

## 设计决定

以用户管理列表当前表头为视觉基准。所有真实表格表头统一使用不透明的 `var(--surface-container-low)` 背景，避免底层渐变改变表头观感；文字使用清晰的表面变体色，并采用适中的统一字重。用户管理现有表头不改变视觉效果。

统一范围：

- 对数结果详情列表表头；
- 对数历史主列表表头；
- 用户管理列表表头；
- 所有弹窗中的真实表格表头；
- 历史详情的三个结果表格表头；
- 三个工具弹窗的列表式表头，仅改变视觉颜色，不改变整体布局。

数据源配置等非表格分区标题不纳入本次调整。

## 主题兼容

- 默认及太空主题使用各主题的 `--surface-container-low` 表面灰色；
- 暗色模式保留独立的深色表头背景，避免文字对比度下降；
- 表头文字颜色、字重、对齐、粘性定位和列宽保持现状。

## 验收标准

- 表头不受页面背景渐变影响；
- 表头视觉上比相邻内容区略深，效果与用户管理列表一致；
- 主列表、弹窗表格和历史详情表格的表头观感一致；
- 非表格标题与三个工具弹窗的整体布局不发生变化；
- 前端静态测试覆盖统一背景声明及布局不变约束。
