# 看板月份格式提示设计

## 目标

在看板管理页面的“输出字段”区域直接说明当前区域 `month` 字段所需格式，避免自定义 SQL 返回格式与看板页面展示规则不一致。

## 展示规则

- 月度信托项目数量：`1月`～`12月`，示例 `8月`。
- 报表对账完成时间：`YYYY-MM`，示例 `2026-08`。
- 报表校验问题处理：`YYYY-MM`，示例 `2026-08`。
- 说明直接写入上述三个内置 `month` 字段的“字段说明”，打开管理字段弹窗即可查看。

## 边界

服务启动时沿用现有内置字段同步机制更新说明，不新增迁移。不修改 SQL 校验、字段协议、接口返回或看板页面解析逻辑；自定义区域和其他字段不显示月份格式说明。

## 验证

目录测试确认三个内置 `month` 字段包含对应格式说明。
