# 全局纯色主题与未来个人覆盖设计

**状态：** 已确认，2026-07-18 进入实施
**取代范围：** 取代 `2026-07-18-theme-color-gradient-preference-design.md` 中所有主题渐变开关、渐变存储、渐变背景、渐变按钮、渐变日期和渐变折线设计；该旧文档的圆角补齐、语义按钮、折线几何和登录统一布局要求继续有效。

## 1. 已确认目标

- 全系统彻底取消主题渐变功能，不保留渐变开关或隐性渐变绘制。
- 默认活力主题色为 `#3F6FAF`，默认沉稳主题色为 `#355F63`。
- 当前由管理员在“系统设置 → 界面设置”中维护两套系统全局主题色。
- 管理员保存后当前页面立即生效；其他已登录用户刷新页面或下次打开后生效。
- 所有用户和未认证登录页都使用系统主题色。
- 为以后开放普通用户个人主题色预留数据层；个人色只影响本人，生效优先级为“个人覆盖色 > 系统默认色”。
- 圆角、折线图风格继续按用户独立保存；默认圆角 `4px`，默认折线风格 `straight`。
- 本次界面变化只影响显示，不改变业务数据、请求参数、表格计算、流程执行、校验、导入或导出功能。

## 2. 明确排除

- 不使用 `app_settings` 保存主题色。
- 不提供颜色选择器、色板、透明度、三位 HEX、`rgb()` 或渐变编辑器。
- 当前版本不向普通用户显示个人主题色编辑入口，也不开放个人主题色写接口。
- 不要求其他已经打开系统的浏览器在不刷新页面的情况下实时变色，不增加轮询、WebSocket 或服务端推送。
- 主题色不得重染语义红/橙/绿、状态徽标、分类图表色或报送流程分类色。
- 不修改已统一的表头背景、文字、边框和高度，不回退最近完成的弹窗表面层级、布局、滚动或留白。

## 3. 数据模型

### 3.1 系统全局主题表

新增独立 `system_interface_preferences` 表，仅允许唯一记录 `id=1`：

| 字段 | 类型 | 约束与含义 |
|---|---|---|
| `id` | `TINYINT UNSIGNED` | 主键，检查约束固定为 `1` |
| `vitality_theme_color` | `CHAR(7)` | 非空，默认 `#3F6FAF`，必须符合 `^#[0-9A-F]{6}$` |
| `calm_theme_color` | `CHAR(7)` | 非空，默认 `#355F63`，必须符合 `^#[0-9A-F]{6}$` |
| `updated_by` | `VARCHAR(64)` | 可空，记录最后修改管理员用户 ID |
| `updated_at` | `DATETIME(6)` | 非空，自动更新时间 |

迁移只建表，不插入业务记录。应用读取不到 `id=1` 时使用代码默认值；管理员首次保存时执行单条原子 upsert。

### 3.2 用户界面偏好表

`user_interface_preferences` 最终包含：

- `user_id`
- `radius_px`
- `line_chart_style`
- `vitality_theme_color NULL`
- `calm_theme_color NULL`
- `updated_at`

两个个人色字段本次保持空值，只为未来个人设置预留。非空时同样必须符合大写六位 HEX。彻底删除 `theme_gradient_enabled` 的模型、API、前端状态、DDL 和文档，不把未部署的中间设计带入数据库。

### 3.3 生效解析

对每个颜色分别解析：

```text
effective_color = valid_personal_override ?? valid_system_color ?? code_default
```

坏值按字段隔离回退，不能因一项坏值丢弃另一项有效值。数据库与服务端均严格校验；前端缓存仅用于首屏显示，不是权威来源。

## 4. DDL 与升级顺序

- 修改尚未部署的 `005_user_appearance_preferences.sql`：只为用户偏好增加 `line_chart_style` 和两个可空个人色字段及检查约束，不再增加 `theme_gradient_enabled`。
- 新增 `006_system_interface_preferences.sql`：创建第 37 张应用表及唯一行约束、颜色约束、默认值和审计字段。
- 更新应用期望架构、SQLite→MySQL 导出后的升级脚本顺序、初始化/部署文档和完整建表语句。
- 不修改已经发布的 `001`–`004`，不重建或删除表，不改 `app_schema_version=1`，不在迁移中更新现有偏好行。
- 完成全部代码与测试后，由主会话对用户指定 MySQL 依次执行 `005`、`006`，执行前后核对列、约束、默认值、表数和现有行数。

## 5. 接口与权限

### 5.1 主题读取

主题读取接口允许匿名访问，以支持登录页：

- 未认证：返回系统色作为最终生效色，能力项均为 `false`。
- 已认证：返回个人覆盖色、系统色、最终生效色和能力项。
- 当前管理员收到 `can_manage_system_theme_colors=true`；普通用户为 `false`。
- 权限只由服务端能力项决定，前端不散落硬编码角色判断。

### 5.2 系统主题保存

- 写接口要求有效登录、CSRF 和 `can_manage_system_theme_colors`。
- 请求必须同时包含活力、沉稳两个完整颜色。
- 仅接受字符串 `#RRGGBB`；允许小写输入，但服务端规范为大写后保存。
- 任一字段非法时整体返回 `400`，不得部分写入。
- 保存记录当前管理员 ID；非管理员返回 `403`。

当前不实现个人主题色写接口。未来开放时复用现有解析器、字段和视觉组件，并新增独立的个人写能力，不改变系统全局接口语义。

## 6. 界面设置与所见即所得

- 界面设置继续展示所有用户可用的个人圆角和折线图风格。
- 仅 `can_manage_system_theme_colors=true` 时展示“全局主题色”区域。
- 区域包含活力、沉稳两个文本输入框及只读颜色预览块，不调用浏览器颜色选择器。
- 只接受 `#RRGGBB`；小写在失焦或保存时规范为大写。
- 有效草稿即时作用于当前页面；非法或未输入完整时显示行内错误、保留上一个有效预览并禁止保存。
- 使用独立“保存全局主题色”按钮，不能和个人圆角/折线风格混成一次请求。
- “恢复默认主题色”把草稿恢复为 `#3F6FAF` / `#355F63` 并立即预览，仍需显式保存。
- 未保存草稿在离开设置页、刷新、退出登录或用户切换时撤销为服务端已保存值。
- 请求 ID、认证修订号、草稿修订号和服务端变更修订号继续防止旧 GET/POST 覆盖新草稿、新用户或新保存结果。

## 7. 纯色主题渲染

### 7.1 根令牌

所有目标组件只消费统一纯色令牌：

```css
--theme-accent: #3f6faf;
--theme-on-accent: #ffffff;
--theme-accent-readable: #3f6faf;
--theme-page-background: #edf2f8;
```

沉稳主题覆盖 `--theme-accent` 为 `#355f63`。不再存在 `--theme-accent-gradient`、`--theme-accent-fill` 的渐变分支或 `data-theme-gradient`。

### 7.2 对比度

- 实心主题面保持管理员保存的原色，`--theme-on-accent` 在黑/白中选择对比度更高者。
- 主题色作为文字、图标、细边框或焦点环时，按当前明暗中性表面向同色系的明/暗方向调整，直到可读；不得改写数据库原值。
- 亮色和暗色模式分别计算可读派生色，图标和文字在两种模式下都必须清晰。
- 错误、警示、成功和禁用状态优先于主题派生色。

### 7.3 覆盖范围

- 主导航选中态、普通主要按钮、非语义选中项和重点图标。
- 输入框、文本域、搜索框、下拉框和日期控件的焦点边框、低透明度焦点环、光标、箭头/日期图标和自定义选中态；输入面和普通选项保持中性。
- 日期面板选中日期、月份标题、翻页、“清除/今天”均使用纯色令牌，不残留组件局部渐变。
- 两类首页折线图使用最终生效主题色；默认直线折线隐藏圆点，平滑曲线保留圆点。
- 应用内容区和登录页使用由主题色低比例混合出的单一纯色背景；不能使用 `linear-gradient` 或 `radial-gradient`。
- 登录页亮色/暗色共用同一居中单卡片布局，只切换中性色、可读派生色和 Logo 资源。

## 8. 登录页缓存

- 本机缓存最近一次成功登录用户的最终生效主题色，登录失败不得污染。
- 认证前脚本严格解析缓存并在 CSS 渲染前设置纯色令牌，避免明显闪烁。
- 无缓存或缓存非法时使用系统默认 `#3F6FAF` / `#355F63`；页面加载后通过匿名只读接口刷新系统色。
- 管理员成功保存系统色时更新当前浏览器缓存；其他浏览器刷新后从服务端获得新值。
- 未来个人色开放后，缓存继续保存最近成功用户的最终生效色，不需要改登录页数据结构。

## 9. 语义按钮、表头与圆角保护

- 普通主要操作使用纯色主题背景；删除/不可逆清空使用危险红，停用/停止/恢复默认使用警示橙，启用/完成使用成功绿，查看/编辑/刷新/导出/取消/返回等使用中性次要样式。
- 按钮颜色指实心背景或弱化形态的文字/图标/边框，由动作含义和层级决定；禁用态统一中性灰。
- 表头保持另一个会话已统一的背景、文字、边框和高度，主题选择器不得匹配或覆盖表头。
- 最近完成的统一弹窗主体白色表面、局部灰色选择/日志区、布局、滚动和留白保持不变。
- 既定遗漏圆角清单继续实施；用户列表头像、角色徽标、状态徽标消费 `--ui-radius`，在线圆点和“我”标识保持专用形态。

## 10. 错误处理与降级

- 系统主题表缺失、记录缺失或读取失败时使用代码默认色，不能阻塞登录或业务页面。
- 保存失败保留管理员当前有效预览并标记未保存；离开页面后恢复服务端值。
- 浏览器不支持 `color-mix()` 时使用 JavaScript 计算的固定 CSS 变量，不依赖渐变或实验性文字裁切。
- 自动对比色计算异常时回退到白/黑中对比度更高者。
- 主题接口失败不影响个人圆角、折线风格或业务 API。
