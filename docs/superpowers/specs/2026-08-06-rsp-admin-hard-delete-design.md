# 报表特殊处理：管理员物理删除

## 结论

管理员可对任意状态的特殊处理记录做物理删除；仅二次确认，不填原因；不可恢复。

## 行为

- 权限：仅 `role=admin`（`can_delete` + API admin 门禁）
- 状态：草稿 / 待处理 / 处理中 / 已完成 / 已作废均可删
- 接口：`DELETE /records/{id}`，请求体含 `row_version`（乐观锁）
- 事务内删除：主表、涉及报表、关联报送、该记录审计日志
- 成功后 best-effort 刷新 `special_governance` 统计
- 台账：管理员操作列显示红色「删除」；确认文案「确认删除该记录吗？删除后不可恢复。」；成功后关闭对应弹窗并刷新列表

## 非目标

- 非管理员删除、软删除、删除原因、删除后审计留存
