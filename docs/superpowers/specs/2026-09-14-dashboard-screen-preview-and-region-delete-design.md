# 看板页面预览与自定义区域删除设计

## 目标

在看板管理页补齐“看板页面”预览，复用 `D:\xiaxin\kanban\kanban-web` 中两个独立 HTML 看板的视觉与布局，并用当前模块的看板聚合 JSON 接口填充页面。同时修复区域启停时因页面持有旧版本号导致的冲突，并允许删除用户新增的区域。

## 边界

- `D:\xiaxin\kanban` 只读，不修改、不启动、不安装依赖。
- 两个独立 HTML 复制到看板管理模块的静态资源目录，运行时不再依赖原目录。
- 看板页面预览使用接近全屏的模态弹窗和同源 iframe；右上角“关闭”和 Escape 可关闭，点击遮罩不关闭。
- iframe 仅请求 `/api/modules/dashboard-management/boards/{board_code}/preview`，不读取原项目接口。
- 自定义区域删除为物理删除，按来源配置、字段、区域顺序在同一事务中完成；内置区域禁止删除。
- 编辑区域前重新读取当前看板目录，使用最新 `row_version`，不移除后端乐观锁。

## 数据映射

- 报表报送大屏按区域稳定编码读取 7 个区域，使用每个区域的 `rows` 与配置字段别名更新原页面组件。
- 报送流程大屏按区域稳定编码读取 3 个区域，动态更新报表数量、报送时间和校验统计三个 SVG 区域。
- 单个区域返回 `status=error` 时保留该区域空态并显示轻量错误提示，不影响其他区域渲染。

## 验证

- 后端覆盖删除权限、内置区域保护、级联删除和预览接口。
- 前端静态测试覆盖预览菜单可用、页面 iframe、关闭方式、页面接口地址和数据区域编码。
- 完整运行 `tests/modules/dashboard_management` 与 `git diff --check`；不执行打包和浏览器视觉检查。
