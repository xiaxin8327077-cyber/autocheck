# 报送导航统计周期与报送时间视觉还原设计

## 目标

仅调整报送导航页面的“统计周期”和“报送流程进度”标题栏中的报送时间，不改变统计卡片、鱼骨图内容、菜单行为或业务数据。

## 视觉基准

以 `C:\Users\jsitc\Desktop\监管智核-报送导航设计稿.html` 及用户提供的设计稿截图为准。现有实现与基准的主要差异是：统计周期被包进整行白色卡片；报送时间卡片使用蓝灰色紧凑样式，而不是设计稿的暖黄色样式。

## 设计

### 统计周期

- 移除整行容器的白色背景、边框、圆角、阴影和模糊效果。
- 沉稳主题在同一行左侧显示“报送导航”，字号、字重与其他页面标题一致；统计周期控件保持在右侧。
- 活力主题不显示该页面标题，统计周期控件仍保持在右侧。
- 标签恢复蓝色文字、字距和前置渐变短横线。
- 下拉框恢复浅蓝半透明背景、蓝色边框、蓝色文字、设计稿尺寸和悬浮反馈。
- 暗色模式保留清晰对比度，不重新增加整行卡片容器。

### 报送时间

- 人行、金监两块报送时间卡片沿用设计稿的淡黄色渐变背景、橙黄色边框和黄色渐变机构标签。
- 恢复设计稿的内边距、圆角、标签字号、正文行高及蓝色日期样式。
- 两块卡片组成一个整体，在“报送流程进度”标题栏中水平居中。
- 卡片内部机构标签与报送时间文字保持左对齐，避免多行内容难以阅读。
- 标题保留在标题栏左侧；通过三列标题栏布局保证时间卡片组相对整张流程卡片居中，而不是只在标题右侧剩余空间内居中。
- 窄屏下回退为上下排列：标题在上，时间卡片组换行并左对齐/自然换行，避免溢出。
- 暗色模式使用设计稿对应的低透明度暖黄色背景和边框。

## 实现范围

- `src/auto_check/web/styles.css`：修改两组组件及其暗色、响应式规则。
- `src/auto_check/web/index.html`：仅在精确居中需要时增加最小布局包装或辅助结构；不改报送日期内容。
- `tests/test_web_static.py`：补充关键结构和样式约束。
- `README.md`：记录统计周期与报送时间视觉还原及居中行为。
- `src/auto_check/web/app.js`：当前版本更新日志保持精简口径“系统优化及BUG修复”。

## 验证

- 静态测试验证统计周期不再使用整行卡片视觉、沉稳主题显示而活力主题隐藏“报送导航”标题、报送时间使用暖黄色样式且卡片组具备整体居中布局。
- 运行完整测试 `python -m pytest -q`。
- 在浅色和暗色模式下，用与设计稿一致的桌面视口进行截图对比。
- 打包前确认 `dist\auto-check.exe` 未运行，再刷新 Windows 可执行文件。
