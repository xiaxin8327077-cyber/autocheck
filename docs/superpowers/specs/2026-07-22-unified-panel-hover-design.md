# 内容模块悬浮描边统一设计

## 目标

将报送导航、对数执行、对数历史、系统设置和用户管理的外层内容模块悬浮反馈统一为对数总览的视觉强度，消除页面之间的主题光晕、纯主题色强描边和阴影层级差异。

## 统一规则

- 外层内容模块保持原有默认背景、圆角和静态边框。
- 悬浮时统一使用 `1px` 浅主题色描边，只修改 `border-color`，不得通过更粗边框强化状态。
- 悬浮时统一上移 `2px`，只保留极轻的内高光。
- 默认和悬浮状态都禁止外投影及 `0 0` 扩散型主题色阴影，不在内容模块缝隙中产生灰边或光晕。
- 规则同时覆盖旧主题选择器和页面专用高优先级选择器，避免旧样式再次覆盖统一效果。
- 不改变按钮、表格行、流程卡片、弹窗和其他内部组件的悬浮行为。

## 作用范围

- 对数总览：主要统计卡与分析内容卡，作为统一视觉基准。
- 报送导航：概览统计区、报送流程进度、报送日程、我的待办四个外层内容区。
- 对数执行：页面直属内容卡。
- 对数历史：页面直属历史内容卡。
- 系统设置：设置仪表盘外层卡片。
- 用户管理：统计卡、筛选栏、用户表格外层卡片。

## 验证

- 静态测试检查上述选择器均进入同一悬浮规则。
- 静态测试检查规则只使用 `1px` 描边和内高光，并且不包含外投影或扩散光晕。
- 运行相关前端静态测试和 `git diff --check`；不重复运行完整测试套件。
