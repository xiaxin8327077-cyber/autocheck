# 智能核数分主题交互设计

## 目标

“智能核数”按主题采用符合各自导航形态的交互：沉稳主题侧边栏通过点击父菜单展开或收回，活力主题顶部导航通过悬浮显示二级菜单并允许点击父菜单进入“对数总览”。

## 交互规则

- 活力主题：悬浮或键盘聚焦“智能核数”时显示顶部下拉菜单；鼠标移出整个菜单区域后自动收起。
- 活力主题：鼠标点击“智能核数”调用现有页面切换逻辑进入 `home`，页面标题仍为“对数总览”；鼠标点击后释放按钮焦点，避免鼠标离开后因 `focus-within` 导致菜单继续显示。
- 活力主题：鼠标点击“对数总览”“对数执行”或“对数历史”后同样释放所点击链接的焦点，保证鼠标离开整个菜单区域后下拉菜单收起。
- 活力主题：键盘激活父菜单时保留焦点，使用户仍可继续 Tab 到二级菜单；Escape 或点击菜单外部释放焦点并收起。
- 沉稳主题：悬浮或聚焦父菜单不自动展开；点击“智能核数”切换展开/收回状态，不跳转页面。
- 点击“对数总览”“对数执行”“对数历史”仍进入各自现有页面。
- 当前页面属于上述三个页面时，“智能核数”父菜单保持激活，但不强制改变用户手动设置的沉稳侧栏展开状态。
- 保留 Escape 和点击菜单外部收起顶部菜单的兼容逻辑，不改变其他一级菜单行为。

## 实现方式

- CSS 仅为 `.top-nav-group` 保留 `:hover` 与 `:focus-within` 展开规则；沉稳侧栏恢复为仅由 `.open` 控制展开。
- JavaScript 在同一个父菜单点击处理器中按 `.nav-group` 与 `.top-nav-group` 分流：沉稳侧栏调用 `setNavGroupOpen` 切换状态，活力顶部导航调用 `switchPage("home")`。
- 活力主题的鼠标点击通过 `event.detail > 0` 与键盘激活区分；仅鼠标点击后调用 `toggle.blur()`，确保鼠标离开时收起，同时保留键盘可访问性。
- 二级菜单链接沿用相同判断，仅鼠标点击 `.top-nav-subitem` 后调用 `item.blur()`；键盘激活时保留焦点。
- `syncNavGroupState` 只维护父菜单激活样式，不再因为进入子页面而强制展开沉稳侧栏。

## 测试与文档

- 静态测试验证沉稳侧栏不存在悬浮/聚焦展开规则，父菜单点击切换 `.open` 且不跳转。
- 静态测试验证活力顶部菜单存在悬浮/聚焦展开规则，父菜单点击进入 `home`，鼠标点击后释放焦点。

## 非目标

- 不修改三个二级页面的业务逻辑、路由标识或数据加载方式。
- 不增加悬浮延时、动画框架或新的移动端专用手势。
