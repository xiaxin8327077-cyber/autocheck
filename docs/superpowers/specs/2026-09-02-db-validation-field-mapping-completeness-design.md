# 人行逐笔校验字段映射完整性修复设计

## 背景

`Zg05_Rule3` 将 ZG05 的 `A5100_除回购和拆借外贷款` 与 ZG07 按产品代码汇总的“贷款余额折人民币”比较。当前全局字段快照包含该字段，但 ZG07 的按表必需字段集合遗漏了它，导致字段映射快照不生成该行，运行时无法把物理列映射成中文业务字段，ZG07 汇总值因而被当作 0。

## 设计

1. 将“贷款余额折人民币”加入 `REQUIRED_CHINESE_FIELDS_BY_SCOPE["ZG07"]`，让字段映射刷新、启动预检和规则读取使用同一份必需字段声明。
2. 增加回归测试，覆盖 ZG07 必需字段声明、映射服务生成映射，以及 `Zg05_Rule3` 读取映射后金额的真实链路。
3. 审计确认 ZG02“初始募集金额”同样是人民币合计规则的必需字段，一并补齐。
4. 将规则用于多机构分组、但缺失时允许沿用兼容默认值的“金融机构编码”和“数据管理机构”按实际读取范围登记为可选字段；缺失时不阻断校验。
5. 将逐笔表直接依赖关系提取为执行引擎和启动预检共用定义；只选择 ZG05 时，预检同时检查其实际读取的 ZG07、ZG08 必需字段。
6. 在规则说明中明确 `Zg05_Rule3` 依赖 ZG07“贷款余额折人民币”的字段映射。

## 边界

- 不修改数据库结构、接口、前端、权限和版本号；不写死任何英文字段名。
- 现有生产应急 SQL 只作为临时措施；代码修复发布并刷新字段映射后由正式映射快照接管。
- 不自动打包、提交或推送。

## 验证

- 先运行新增回归测试并确认修复前失败、修复后通过。
- 运行逐笔校验相关测试、全量测试和 `git diff --check`。
