# 管理列表撑满与看板表面统一设计

## 目标

- 字典管理、定时任务管理在数据不足时与角色权限页一致，占满主内容区剩余高度。
- 看板管理的外层内容块使用系统标准卡片边框色和内容背景色。

## 方案

1. 为 `#page-dictionaries` 与 `#page-scheduled-tasks` 增加 `height: 100%`、`min-height: 0`。继续复用现有 `.result-card` 和 `.table-wrap` 的 flex 布局，不生成占位行。
2. 字典管理、定时任务管理和用户管理统一复用角色权限页的分页 DOM 与 CSS：分页栏固定在列表卡片底部，空数据或不足一页时也显示总数、页码、前后翻页和跳页框。字典主列表补充分页，复用系统设置的每页显示条数和现有通用分页计算；筛选变化后回到第一页。
3. 看板顶部切换栏与下方内容区放入同一个外层卡片；外层直接使用平台 `--outline-variant`、`--surface-container-lowest` 与 `--ui-radius`，并通过 `overflow: hidden` 统一裁切四角。内部只保留系统分隔线，标题栏使用 `--surface`，左右内容区使用 `--surface-container-lowest`。
4. 鼠标进入看板内容卡片时，外层边框使用与系统主内容面板一致的主题色混合描边；不增加光晕、阴影或位移。
5. 所有选择器保持页面或模块作用域，不修改数据读取、保存及任务执行逻辑。

## 验证

- 静态测试锁定两个管理页面的满高规则、三个管理页面的统一底部分页结构和字典分页行为。
- 看板模块静态测试锁定单一外层卡片、平台颜色变量、系统圆角裁切与纯描边 hover，禁止重新拆成两块边框或引入硬编码近似色。
- 运行相关前端测试与 `git diff --check`。
