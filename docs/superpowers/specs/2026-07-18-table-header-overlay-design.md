# 表格表头半透明灰色统一设计

## 背景

当前主列表、历史详情及弹窗表格的表头使用不透明浅灰色，而内容面板会透出页面主题背景。两者对底层背景的处理不同，使表头在带渐变的页面上反而显得更浅，且不同位置的视觉深浅不一致。

## 设计决定

表头背景统一改为半透明灰色遮罩，不再使用由两个不透明表面色混合得到的实色。遮罩允许页面主题背景继续透出，同时提供稳定的灰色覆盖，使表头始终比相邻内容区深一档。

统一范围：

- 系统主列表表头；
- 所有弹窗中的真实表格表头；
- 历史详情的三个结果表格表头；
- 三个工具弹窗的列表式表头，仅改变视觉颜色，不改变整体布局。

数据源配置等非表格分区标题不纳入本次调整。

## 主题兼容

- 默认及太空主题使用基于表面灰色和透明色混合的半透明遮罩；
- 暗色模式保留独立的深色半透明遮罩，避免背景过亮或文字对比度下降；
- 表头文字颜色、字重、对齐、粘性定位和列宽保持现状。

## 验收标准

- 表头能够透出页面背景渐变；
- 表头视觉上比相邻内容区略深，不形成明显色块；
- 主列表、弹窗表格和历史详情表格的表头观感一致；
- 非表格标题与三个工具弹窗的整体布局不发生变化；
- 前端静态测试覆盖统一背景声明及布局不变约束。
